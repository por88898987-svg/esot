Privacy-first static checker

BreachSignal

A GitHub Pages-ready helper that guides users to the right official breach tools without storing their data. The site validates the entry locally in the browser, then sends the user only to trusted providers.

0 server-side logs by default. Everything on this page runs in the browser.

Check Input

Choose what you want to scan

Email addresses work best with breach-search tools. Phone numbers are usually handled by monitoring products that verify ownership first.

Nothing is uploaded anywhere from this page. Validation stays local.

Enter an email address or phone number, then this page will recommend the safest official services to use.

Why this design?

Public static hosting is perfect for the interface, but real breach APIs often require keys, rate limits, or verified ownership. This site avoids pretending otherwise.

GitHub Pages friendly

No build step, no backend, and no dependency install. Drop the folder into a repository and publish.

Good privacy baseline

Keep the site static, avoid analytics, and do not proxy user identifiers through your own server unless you truly need an authenticated API integration.

How to ship it

Three-step publish flow

  1. Create a new GitHub repository and upload this folder.
  2. In repository settings, enable GitHub Pages for the root or main branch.
  3. Open the published URL and test both the email and phone flows on mobile and desktop.
This project is a guided breach-check launcher, not a hidden scanner. If you later want direct email breach lookups, we can add an optional API-backed mode behind a small serverless function and a private key.
